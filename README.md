# powerpuff

Общее решение для агентной разработки программных систем: вечером человек доводит спеку, ночью код пишется без него, утром он разбирает карточки решений и вопросов. Не привязано к проекту или стеку.

## Принципы (каждый — с замером или источником, см. `docs/research/`)
| Принцип | Основание |
|---|---|
| Оркестратор — скрипт, а не модель | модель-оркестратор стоила $11.42 на спеке, которую plain делает за ~$1 |
| «Готово» решает скрипт (`forge_check.py`) | слово модели не считается; приём победителя Build Day (Tekton) |
| Приёмочные тесты пишутся до кода в отдельном контексте и замораживаются по sha256 | 25% пойманных дефектов против 14% у тестов после кода |
| Один писатель, один контекст на единицу работы | параллельные писатели конфликтуют; повторное чтение репозитория — главная статья расходов |
| Сильная модель только на аудит спеки и приёмку, дешёвая пишет | по качеству ничья, по цене выигрыш |
| Мелкие единицы (дифф до ~200 строк) | мелкие правки сливаются заметно чаще |
| Ничего без измеренной пользы | роли и ритуалы bob-pipeline на бенче стоили в 5–20 раз больше при том же или худшем качестве |

## Состояние
| Компонент | Статус |
|---|---|
| `/forge` — одна спека под ключ (`scripts/forge_run.py`) | прототип, проверяется на реальной спеке и на bob-bench |
| `forge_check.py` | есть |
| Линтер спеки, очередь единиц с worktree на единицу, утренние карточки, профиль проекта | по дизайну `docs/design-system.md`, не построено |

## Запуск
```
python scripts/forge_run.py <каталог спеки | файл | текст> [--repo .] [--model opus] [--writer sonnet] [--max-usd 60] [--max-hours 8] [--preflight]
```
Результат: `.forge/REPORT.md`, последняя строка вывода `FORGE: done|failed`. Повторный запуск продолжает с места остановки.
