## B. Research (`docs/research/`)
| # | Finding | Source | Consequence | Status |
|---|---|---|---|---|
| B1 | Tests written separately from the code catch 25% of defects, after the code — 14% | multi-agent-evidence | acceptance tests before the code, in a separate context, freeze | accounted for |
| B2 | "The strong one leads, the cheap one writes": a tie on quality (62 versus 60%), a win on price | same | the strong model only for audit and acceptance; verify by ablation | to verify (stage 1) |
| B3 | Planning mostly lowers the price for strong models rather than raising quality | same | do not complicate planning | accounted for |

| B6 | About a third of tokens goes to checking and fixes | harness-survey | reserve a third of the budget for fixes | planned, stage 4 |
| B7 | Model judges alone are unreliable | multi-agent-evidence | model-based checking is advisory | accounted for |
| B8 | In 1,210 merged agent bug-fix PRs (Python, the AIDev set, about 80% Codex) SonarQube found 1,190 new issues: about 89% code smells (duplicated string literals, cognitive complexity, unused parameters), about 4% bugs; percentages computed by us from the paper tables (arXiv 2601.20109), re-checked 2026-11-17 | quality-gates-evidence | cheap gates on complexity and duplicates, on new code only | planned, stage 2 |

| B11 | Claude Code hooks: exit code 2 blocks in PreToolUse and Stop | same | the same scripts work in attended mode | planned, stage 6 |
| B12 | The agent can tweak the allow-list of old violations itself | same | compare it with the base commit | planned, stage 2 |
