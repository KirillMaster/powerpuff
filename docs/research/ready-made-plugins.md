## Verdict
- No tool found covers >=80%. My estimate for the best (cortex-command) is roughly 35-45% (inference, not measured). Nothing found combines script orchestrator + frozen pre-written acceptance tests + tiered models + cumulative budget + rate-limit resume. This is absence of evidence from a finite search; I read about a dozen READMEs.
- Do not adopt wholesale; building is justified. Reuse rather than rebuild:
  - Morning deferral format: cortex-command deferred/{slug}-qNNN.md with blocking/non-blocking/informational severity, blocking first (docs/overnight.md). Its warning that non-blocking deferrals become committed code applies to you too.
  - Evening side (a): cortex-command /refine and spec-kit clarify/analyze as prompt prior art.
  - Rate-limit resume: pattern from claude-auto-continue / overnight-cli (parse reset time, claude --resume, retry cap); verify before trusting.
  - ai-orchestrator: oracle must fail on original code check and control fingerprinting. Nightshift: control-file snapshot + hard reset, log-parsed RECURSIVE_BUDGET cap.
  - Test protection: PreToolUse deny on test paths + CI diff check + holdout outside workspace (S); read-only tests reduce but do not stop cheating, so layer.
  - gh-aw safe-output split (read-only agent, separate write job opens PR) for per-unit PRs.
- Your differentiators remain: frozen test hash, gate-decided done with anti-tamper, model tiering, cumulative cap, per-unit PR.
